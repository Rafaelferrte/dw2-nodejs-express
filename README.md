# DW2 — Desenvolvimento Web 2

Repositório de estudos e atividades desenvolvidas durante a disciplina de Desenvolvimento Web 2 na Fatec.

O conteúdo reúne exercícios práticos de JavaScript e desenvolvimento com Node.js, explorando conceitos fundamentais de programação e desenvolvimento web no backend.

## Conteúdos abordados

- Fundamentos de JavaScript, funções e estruturas de dados.
- Arrays, objetos, datas e manipulação de strings.
- Introdução ao Node.js e Express.
- View engines e organização de aplicações web.
- Desenvolvimento de aplicações CRUD.
- Organização de projetos com controllers, models e views.

## Organização

Os diretórios estão organizados por aulas, exercícios e atividades práticas, permitindo acompanhar a evolução dos conteúdos estudados.

## Objetivo

Consolidar conhecimentos de programação JavaScript e desenvolvimento backend por meio de exercícios e projetos acadêmicos.

**Tecnologias:** JavaScript · Node.js · Express
